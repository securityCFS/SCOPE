# Project Repository Guide (Example)

Place a tailored `AGENTS.md` or `CLAUDE.md` in each project repository root.

## Environment & Data Contracts

- Confirm the active Python/Conda environment and dataset mount paths before starting runs.
- Preserve baseline config files; create new config files or explicit overrides for new experiments.
- Separate completed runs (with final metrics and artifacts) from partial logs or failed starts.
- Include direct paths or relative links to generated figures, logs, and checkpoints in your final summary.
