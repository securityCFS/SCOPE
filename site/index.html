Local-First & Self-Hosted Remote

127.0.0.1 by default. Private mobile access on your terms.

No third-party cloud relay, no telemetry, no account lock-in. Expose your personal workbench to your phone or laptop via Tailscale Serve or your own Caddy + SSH reverse tunnel.

Workstation or Private Linux Hub

Built-in Private Gateway (:4820)

03

Tailscale Serve or Your Own Caddy

Plugin Protocol v1

Extend SCOPE without touching a line of core code.

Plug in Slurm, Kubernetes, Aliyun DLC, WandB dashboards, or custom cluster scripts via a declarative scope-plugin.json manifest, SHA-256 integrity receipts, explicit lifecycle hooks, and auto-rendered Settings UI forms.

  • Manifest-driven settings forms & action buttons rendered automatically in Settings → Plugins
  • SHA-256 receipt verification & clean reverse-order onDispose() teardown
  • Full CLI lifecycle: scope plugin inspect / add / list / remove
Read Plugin Protocol v1 →
scope-plugin.json protocol v1 
{
  "protocolVersion": 1,
  "id": "slurm-inspector",
  "name": "Slurm Queue Inspector",
  "entry": "./index.mjs",
  "permissions": ["ssh:exec", "network:read"],
  "settings": [
    { "key": "host", "label": "Login Host", "type": "string" }
  ],
  "actions": [
    { "id": "squeue", "label": "Refresh Queue" }
  ]
}
